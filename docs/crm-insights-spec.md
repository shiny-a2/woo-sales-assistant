# دستور برای کلاد‌کدِ افزونهٔ CRM (a2-crm) — اندپوینتِ «شناختِ مشتری» برای مغزِ فروش

این متن را عیناً به کلاد‌کدی که روی افزونهٔ a2-crm کار می‌کند بده. مغزِ فروش (سرور، woo-sales-assistant)
می‌خواهد برای هر مشتری «شناختِ کامل» بگیرد تا در گفتگو بداند با چه کسی صحبت می‌کند.

## اندپوینتِ موردنیاز

```
GET /wp-json/a2crm/v1/customer-insights?phone=09xxxxxxxxx
Header: X-A2-Token: <همان توکنِ فعلیِ a2crm>
```

- `phone` با هر فرمتی (0912… / 98912… / +98…) پذیرفته و با «۹ رقمِ آخر» تطبیق داده شود.
- به‌جای phone می‌تواند `tg_id` یا `ig_id` یا `wa_id` هم بیاید (هر کدام موجود بود).

## خروجیِ موردانتظار (JSON)

```json
{
  "ok": true,
  "found": true,
  "contact": {
    "first_name": "…", "last_name": "…", "phone": "…",
    "city": "…", "tags": ["…"], "level": "…", "customer_label": "…",
    "ig_id": "…", "tg_id": "…", "wa_id": "…"
  },
  "viewed_products": [            // محصولاتی که این مشتری در سایت دیده (جدید → قدیم، حداکثر ۲۰)
    {"id": 123, "name": "…", "url": "…", "viewed_at": "…", "views": 3}
  ],
  "recommended_products": [       // خروجیِ موتورِ پیشنهادِ خودِ افزونه (اتریبیوت‌های مشترکِ پُرتکرارِ بازدیدها)
    {"id": 456, "name": "…", "url": "…", "score": 0.83, "shared_attributes": ["برند: سیکو", "نوع موتور: اتوماتیک"]}
  ],
  "visits": {"total": 12, "last_at": "…"},
  "orders_count": 2
}
```

نکته‌ها:
- اگر مشتری پیدا نشد: `{"ok": true, "found": false}`.
- سبک و سریع باشد (کوئریِ ایندکس‌دار)؛ مغز آن را برای هر گفتگو با کَش ۱۲ساعته صدا می‌زند.
- اگر بخشِ «محصولاتِ دیده‌شده» و «پیشنهاد» الان در افزونه جدا هستند، همین‌جا در یک پاسخ تجمیع شوند.
- خطاها با HTTP 200 و `ok:false` + `error` برگردد (مغز retry نکند).

## سمتِ مغز (از قبل آماده شده)

مغز بعد از آماده‌شدنِ اندپوینت، با این دو کلید در `.env` وصل می‌شود — چیزِ دیگری لازم نیست:

```
CRM_INSIGHTS_URL=https://www.javaherian-gallery.com/wp-json/a2crm/v1/customer-insights
CRM_INSIGHTS_TOKEN=<توکن>
```

مغز خروجی را واردِ پروفایلِ واحدِ DNA می‌کند (crm بخشِ viewed/recommended) و در هر گفتگو
به‌صورتِ «🧬 شناختِ مشتری» به مدل تزریق می‌شود (برندها/سلیقه/بازدیدها/پیشنهادها).
